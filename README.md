# Network Recon & Service Enumeration Tool

A Python-based cybersecurity project for learning network reconnaissance,
host discovery, port scanning, and service enumeration in an authorized lab environment.

## Current Status

🚧 Project under development.

## Technology

- Python
- Nmap
- Linux
- Git

## Objective

The goal of this project is to understand and automate basic network
reconnaissance while learning how network services and exposed ports
contribute to an application's attack surface.

## Planned Features

- Host discovery
- Port scanning
- Service detection
- Result parsing
- Basic enumeration
- Report generation

## Disclaimer

This tool is intended for authorized security testing and educational
laboratory environments only.
